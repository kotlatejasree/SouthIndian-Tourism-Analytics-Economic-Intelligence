# South Indian Tourism Analytics & Economic Intelligence

## Project Overview

This project focuses on analyzing tourism data from South India to identify tourism trends, economic patterns, tourist volumes, revenue patterns, and data-quality issues.

The project combines **Python, SQL, Excel, Power BI, and data-quality analysis** to transform raw tourism data into meaningful analytical insights.

## Project Objectives

* Clean and validate tourism data
* Identify data-quality issues
* Analyze domestic and foreign tourist activity
* Analyze tourism revenue
* Perform SQL-based analysis
* Build Power BI visualizations
* Generate analytical outputs and insights

## Tools & Technologies

## Data Quality

The data was investigated for issues such as:

* Missing values
* Invalid or inconsistent records
* Negative values
* Incorrect totals
* Data consistency

The identified issues and validation results are documented in the data-quality report.
